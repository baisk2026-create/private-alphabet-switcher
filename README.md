Build a modern, minimal, dark-themed SaaS landing page for a Windows utility app using React, Tailwind CSS, and Lucide icons.

Project Name: Auto Layout Switcher

Hero Section:

Headline: "Auto Layout Switcher. The Keyboard Switcher That Doesn't Spy on You."

Subheadline: "A lightweight, privacy-first alternative to Punto Switcher. 100% local. Zero telemetry. No internet access required."

Primary CTA Button: "Get for Windows - $4.99". (Make this prominent).
